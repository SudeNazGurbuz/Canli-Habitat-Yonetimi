# Canlı Habitat Yönetimi

Java ile hazırlanmış bir orman habitatı konsol uygulaması. Kullanıcı; habitatı görüntüleyebilir ve gül, ökse otu, sivrisinek veya at ekleyebilir. Habitatın kapasitesi 3 canlıdır.

## Çalıştırma

Eclipse'te projeyi içe aktarın ve `Demo.java` dosyasındaki `main` metodunu çalıştırın. Proje Java 22 ayarını kullanır.
